# Binary Tree Level Order Traversal

Dada a raiz de uma arvore binaria, retorne os valores dos seus nos organizados nivel por nivel, da esquerda para a direita (ou seja, percorrendo a arvore em largura, camada por camada, de cima para baixo).

## Exemplo 1
Entrada: raiz representada em nivel como 3, 9, 20, null, null, 15, 7
Saida: nivel 0 = (3); nivel 1 = (9, 20); nivel 2 = (15, 7)

## Exemplo 2
Entrada: raiz = (1)
Saida: nivel 0 = (1)

## Exemplo 3
Entrada: arvore vazia
Saida: lista vazia

## Restricoes
- O numero de nos na arvore esta entre 0 e 2000.
- -1000 <= valor do no <= 1000
